# BoozeBunk Backend

This folder contains the backend services for the BoozeBunk project, built using [tRPC](https://trpc.io/) and powered by [Bun](https://bun.sh).

## Features

- **tRPC API**: Type-safe, end-to-end API layer.
- **Bun Runtime**: Fast, modern JavaScript runtime for backend services.
- **Modular Structure**: Easy to extend and maintain.
- **Fastify**: Fast, modern web framework for backend services.

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) v1.2.16 or higher installed globally.

### Installation

Install dependencies:

```bash
bun install
```

### Running the Server

Start the backend server:

```bash
bun dev
```

## Project Structure

- `main.ts` - Entry point for the backend server.
- `utils/` - Utility functions and helpers.
